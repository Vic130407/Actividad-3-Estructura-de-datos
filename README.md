# Actividad-3-Estructura-de-datos
Esta actividad esta diseñada para descifrar una clave oculta dentro de 2 conjuntos de numeros en donde cada uno se resuelve de forma diferente, para despues de acceder al programa requerido la clave obtenida, poder recorrer un laberinto desde la salida hasta el final, encontrado la ruta mas corta.
En el primer desafio (recursividad.java), el programa recibe 3 conjuntos de numeros, los cuales debe de descifrar al sumar cada uno de sus digitos hasta que solo quede uno, de esta forma, una vez se descifren los tres conjuntos, el programa obtendra la primera parte de la clave que consta de los primeros 3 digitos.
En el segundo desafio(Divide_y_venceras.java) el programa recibe una matriz con multiples conjuntos de numeros de 3 digitos, el programa debe de ir segmentando la matriz poco a poco hasta que obtenga los valores separados, una vez llega a ese punto, va comparando los valores hasta devolver el mayor de todos, siendo este la segunda parte de la clave.
Para el terccer desafio (Main.java), se ingresa un archivo .txt con un laberinto que se va a usar y se ejecuta, el programa va a recorrer el laberinto por su cuenta, buscando cada paso disponible sin visitar los lugares ya visitados, en caso de que se encuentre en un punto de no retorno, el programa dara un paso atras e intentara recorrer el camino otra vez, ademas el programa va a estar buscando y actualizando constantemente el camino mas corto hasta que ya no encuentre ningun otro, asegurandose asi de entregarle al usuario la solucion mas optima.
